將平台掛在免費網路空間 (各分校永久固定網址)

免伺服器費用，各分校電腦或手機點開同一網址即可同步

步驟 1：下載本平台完整 HTML 檔案

點擊下方按鈕即可將當前完整的單一網頁程式下載至您的電腦 (名為 index.html)。

A 方式一：Netlify Drop 免費託管 (最簡單，30秒搞定，無需帳號)

  1. 打開免費網頁託管服務 Netlify Drop (點此開啟)。
  2. 把剛剛下載的 index.html 放到一個新資料夾（如「口說課平台」）。
  3. 直接將資料夾拖曳進 Netlify 畫面，立即生成固定專屬網址 (例如 https://your-branch.netlify.app)。
  4. 將該網址發送給各分校即可！

B 方式二：GitHub Pages (免費且永久穩定)

  1. 登入 GitHub 建立一個公開儲存庫 (Repository)，例如 talkmaster-booking。
  2. 將下載的 index.html 上傳至該儲存庫。
  3. 到 Settings > Pages，Branch 選擇 main 並儲存。
  4. 即可獲得永久免費專屬網址 (例如 https://your-org.github.io/talkmaster-booking)。

C 方式三：Vercel (免費高效能 CDN)

前往 Vercel 選擇 Deploy Project，將含有 index.html 的資料夾或 GitHub 關聯上傳，即可享有全球 CDN 高速存取。

正式營運資料庫連線 (Supabase)

提供 100% 穩定、不漏單的跨分校即時持久化資料庫

💡 為什麼建議設定專屬 Supabase 資料庫？

公共臨時測試通道在高峰期可能遇到網路限速或跨域快取，而 Supabase（免費提供 500MB PostgreSQL，足夠使用數年）能保證全台分校電腦、平板、手機在任何時間點打開，都連上同一個權威資料庫，達到 100% 同步！

在 Supabase SQL Editor 執行此指令建立資料表： 
CREATE TABLE IF NOT EXISTS public.lesson_hub_state (
  id TEXT PRIMARY KEY,
  payload JSONB NOT NULL,
  updated_at BIGINT NOT NULL
);
ALTER TABLE public.lesson_hub_state ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read-write" ON public.lesson_hub_state FOR ALL USING (true) WITH CHECK (true);
ALTER PUBLICATION supabase_realtime ADD TABLE public.lesson_hub_state;
